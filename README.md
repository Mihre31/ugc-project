# UGC AI Video Generator

A full-stack SaaS platform that generates short-form marketing videos using AI.

Users can upload product images and generate promotional content optimized for social media.

## Tech Stack

Frontend
- React
- TypeScript
- Vite
- TailwindCSS

Backend
- Node.js
- Express

Database
- PostgreSQL
- Prisma ORM

Services
- Clerk Authentication
- Cloudinary Media Storage
- AI Video Generation API

## Features

- AI generated marketing videos
- Project creation and management
- Image uploads
- Credit-based generation system
- Real-time generation status
